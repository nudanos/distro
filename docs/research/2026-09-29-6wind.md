# 6WIND's public repositories: what helps NuDanOS

Reviewed 2026-09-29: https://github.com/orgs/6WIND/repositories (47 repos).

## Summary

There is no reusable 6WIND code here. 6WIND's router (6WINDGate / VSR) is
proprietary, and its large open-source work lands upstream in DPDK and FRR rather
than in this org. The org holds product demos and forks. The four actively
updated forks (containerlab, accel-ppp, netconf, das-schiff-network-operator)
carry **zero commits of their own**: they are contribution staging or bookmarks.
Their value is pointing at upstream projects NuDanOS can use.

## Worth adopting

| Upstream | Via | Use for NuDanOS | When |
|---|---|---|---|
| [srl-labs/containerlab](https://github.com/srl-labs/containerlab) | 6WIND/containerlab, 6WIND/vsr-labs | Multi-router scenario topologies (spec §8.4). vsr-labs shows a vendor router OS demoed with containerlab. Evaluate against hand-rolled QEMU orchestration before writing `distro-build test --topology`; containerlab also runs VM images (vrnetlab) | Plan 3 |
| [nemith/netconf](https://github.com/nemith/netconf) | 6WIND/netconf | Go NETCONF *client* for the NETCONF scenario tests (`get-config`/`edit-config`). The server side stays the libnetconf2 port of netconfd | M1.1 tests |
| [accel-ppp/accel-ppp](https://github.com/accel-ppp/accel-ppp) | 6WIND/accel-ppp | High-performance PPPoE/IPoE/L2TP server (BNG). DANOS only had a PPPoE client | Feature idea, after M2 |
| supervision-grafana (6WIND's own) | — | Pattern for a monitoring stack (InfluxDB + Grafana dashboards). NuDanOS has SNMP only; streaming telemetry (Telegraf/Prometheus exporter or gNMI) is a gap | Feature idea, after M1 |
| [telekom/das-schiff-network-operator](https://github.com/telekom/das-schiff-network-operator) | 6WIND/das-schiff-network-operator | Kubernetes operator driving netlink, eBPF and FRR from CRDs. A pattern for exposing configd's YANG model declaratively | Idea, later |

## Not useful

- `quagga`, `zrpcd`: Quagga contributions and an SDN RPC shim. Quagga is dead; FRR succeeded it.
- `sysrepo`, `libyang`, `libnetconf2`, `Netopeer2`, `pyang` forks: stale 2020 snapshots. Use upstream.
- `networking-6wind`, `fp_*`, `os-vif-*`, `nova-vif-plug-example`: OpenStack glue for 6WIND's proprietary fast path.
- Jenkins, buildbot, collectd, libvirt, ovs and other old forks: no unique content.
