Do not merge this proposed persistence design. A stronger integration test found
that configd's successful public Commit already calls Save. Holding the proposed
password writer lock across Commit therefore nests that lock and times out after
RUNNING changes. A real appliance API commit also persisted its startup marker.
The prior assumption that public API Commit leaves unrelated committed-but-unsaved
state is false for this build. Earlier design/source-review approval is superseded.
The historical reboot-failure fixture remains preserved; attribution to a missing
RPC Save is being investigated through the actual PAM renewal path.
